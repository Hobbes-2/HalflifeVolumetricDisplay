Halflife Linear Volumetric Display

This project is for week 4 of Hackclub Half-life; displays. It is a 8x8 matrix attached to a motor that moves it up and down, running off of an Orpheus Pico. I orginally wanted to make this a spinning display, but then I would have had to use slip rings, which I didnt have time to implement (when do i ever).
Im taking some inspiration from this video (https://www.youtube.com/watch?v=KgT20tHpk1g), but adjusting the model a bit. This is a project Id actually really like to iterate and improve upon once i build it once. The hardest part of this project was honestly the CAD, as the dimensions and mechanical works of it had to be somewhat precise.
